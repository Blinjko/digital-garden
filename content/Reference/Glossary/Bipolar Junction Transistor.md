## Definition
A Bipolar Junction Transistor (BJT) is a 3 terminal circuit element which is made using semiconductors like silicon. BJT's, and transistors in general, serve many different purposes in circuits and are widely used in modern circuits.

BJT's are particularly useful because they essentially allow us to control a larger current with a smaller current. This allows them to be used as [[Amplifier|Amplifiers]].

## Technical Details

### NPN vs PNP
NPN and PNP are the two types of BJT's. The only difference is the order of the doped semi-conductors that they are made up of. 

In an NPN we have
- Emitter - N-type
- Base - P-type
- Collector - N-type

In a PNP we have the opposite
- Emitter - P-type
- Base - N-type
- Collector - P-type
#### Saturation
Occurs when $V_{be} \ge 0.7$ / $V_{eb} \ge 0.7$ and $V_{bc} \ge 0.7$ / $V_{cb}\ge0.7$. 
I.E Both junctions with the base are forward biased.
