## Definition
When a [[Bipolar Junction Transistor]] is in cutoff mode it is essentially not operating at all. There is very little no current flowing through the device.

## Technical Details
To be in cutoff mode, all junctions need to be reverse biased. So for an NPN / PNP we have
$$
V_{be} \lt 0.7 \text{ / } V_{eb} \lt 0.7
$$
and
$$
V_{bc} \lt 0.7 \text{ / } V_{cb} \lt 0.7
$$
