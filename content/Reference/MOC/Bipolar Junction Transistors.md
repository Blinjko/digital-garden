## Context

### Reverse Bias / Forward Bias
I will define these terms in the context of BJT's.

Junction A-B is forward biased if $V_{A}-V_{B} \ge V_{t}$, where $V_{t}$ is some threshold voltage.
Junction A-B is reverse biased if $V_{A}-V_{B}\lt V_{t}$.

The threshold voltage is usually between 0.4 and 0.7 volts. If the difference starts rising above 0.4 the junction is becoming forward biased. If it is at or above 0.7 it is definitely forward biased. And, in general, if it is below 0.4 we say it is reverse biased. 

### Notation

#### NPN / PNP Notation
I will present the conditions for NPN / PNP simultaneously, and I will do it like NPN_COND / PNP_COND. So NPN condition before the / PNP after the slash.

#### Terminal Voltage Notation
Voltages at a terminal with reference to ground are noted as $V_{n}$, where n is the first letter of the terminal name. So $V_{e}$ is the emitter voltage. If there is 2 letters in the subscript like $V_{be}$, this is shorthand for $V_{b}-V_{e}=V_{eb}$. Also typically we would call the "Base-Emitter Voltage" $V_{be}$, this pattern applies through all the terminals.
