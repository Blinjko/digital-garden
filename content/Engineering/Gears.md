Module (m): the unit to represent gear tooth sizes
Pitch (p): the distance between 2 identical spots on adjacent teeth. 
Circular pitch (CP): denotes the reference pitch ( a way to size gears)
Diametral pitch (DP): another way to size gears
Pressure Angle ($\alpha$): the leaning angle of the gear tooth, usualy is 20 degrees
Tooth Depth (h): the distance between the tooth tip and root
Addendum (h$_a$): distance between reference line and tooth tip
Dedendum (h$_f$): distance between reference line and tooth root
Tooth thickness (s): thickness of the tooth
Reference diameter (d): diameter used when talking about the size of circular gears
Tip diameter (d$_a$): diameter of the gear at the tooth tips
Root diameter (d$_f$): diameter of the gear at the tooth roots
Number of teeth (z)
Center distance (a): the distance between the centers of 2 meshed gears
Backlash (j): play between tooth surfaces
Tip & root clearance (c): distance between tooth root and tooth tip of 2 meshing gears

#### Equations
$p = \pi\\m$
$DP = \pi / CP$
$m = CP / \pi$
$m = 25.4 / DP$
$h_a = 1.00m$
$h_f = 1.25m$
$h = h_a + h_f$
$h = 2.25 m$
$s = \pi\\m/2$
$s = p/2$
$d = zm$
$d_a = d + 2m$
$d_f = d -2.5m$
$a = (d_1 + d_1) / 2$
(the subscripts 1, and 2 indicate values for two different gears)
$c_1 = a - (d_{a2} + d_{f1}) / 2$ ( this is in reference to gear 1's root to gear 2's tips)
$c_2 = a - (d_{a1} + d_{f2}) / 2$ ( this is in reference to gear 2's root to gear 1's tips)
$c = 1.25m - 1.00m = 0.25m$ (unclear wheather this is what clearance should be, because by default there should be 0 clearance)
