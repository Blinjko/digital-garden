## Synopsis
So I bought a hoverboard for it's motors, and also scored 2 hackable microprocessors. So, the purpose of this project is a few things.
1. Learn to hack and reprogram the microprocessors.
2. Learn how to program an ESC for a sensored BLDC, first using the hacked microprocessors since they already have the required power circuitry and connections.
3. Learn how to create the power circuitry needed to drive a BLDC and use the existing microprocessor, or get another one to implement the ESC.
4. Create a battery charger circuit for the 6 cell lithium battery pack that I pulled out of the hoverboard.
5. And if were feeling spicy, delve into BMS systems, and making a simple BMS for the 6 lithium cells.
