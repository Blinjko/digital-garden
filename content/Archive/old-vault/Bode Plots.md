Bode Plots are a technique to create a [[Magnitude Plot]] and a [[Phase Plot]] a [[Transfer Function]] of a [[System]] by hand. In reality it is an approximation of the actual graph but it is quick and easy to do. Nowadays we would likely just use a computer to plot the result, but before computers were commonplace engineers needed a different method.

## Plotting
First we [[Normalize Transfer Function]] and then discern the [[Transfer Function Poles]] and [[Transfer Function Zeros]], and their respective [[Oder of a Polynomial|order]]. There are four different cases we have to consider, for magnitude and phase.
1. The [[Bode Plot Constant Case|constant case]]
2. The [[Bode Plot Zero Case|zero case]], where we have a [[Transfer Function Poles|pole(s)]] or [[Transfer Function Zeros|zero(s)]] at zero.
3. The  [[Bode Plot First Order Case|first order case]]
4. And Finally, the [[Bode Plot Second Order Case|second order case]]
