A system can be through of as an entity of sorts that takes in some input and gives some output. Of course this is very vague and many things can fit this description, but in reality that is because they are all systems.

Systems can be realized in various forms, physical, mechanical, electronic, digital, etc. The theory surrounding systems and analyzing their behavior is still generally done through the same methods however. I'm an Electrical Engineering student so I will naturally be talking about systems from their perspective, but alas.

## Classes of Systems
Generally speaking, we find that many systems have the same properties and traits to them, so we naturally we bundle them together and give them names. Some of these properties are
- [[Causal Systems]] / [[Non Causal Systems]]
- [[Time Invariant Systems]] / [[Time Variant Systems]]
- [[Linear Systems]] / [[Non-Linear Systems]]

A common combination of these classes is LTI, [[Linear Time Invariant Systems]], which is simply a system that obeys those two properties.
