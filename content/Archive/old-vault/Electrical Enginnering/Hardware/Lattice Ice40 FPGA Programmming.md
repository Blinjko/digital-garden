Get the oss-cad-suite from yosys HQ, it comes prepackaged with all the tools and libraries and is easy enough to use, saves the headache of trying to install or build everything.

### Synthesizing and programming
Assuming we have a Verilog file and a .pcf file (pinout file) in the current directory.
`yosys -p "synth_ice40 -top top -json my_project.json" my_project.v # synthesize`
`nextpnr-ice40 --hx1k --package tq144 --json my_project.json --pcf my_project.pcf --asc my_project.asc`
`icepack my_project.asc my_project.bin`
`iceprog my_project.bin`

Assuming we have a VHDL file and a pcf file.
`ghdl -a --std=08 my_project.vhdl` - maybe this is not needed?
`yosys -m ghdl -p "ghdl --std=08 my_project.vhdl -e top_module_name; synth_ice40 -top top_module_name -json output.json"`
the rest is the same as above


Few things of note
- the .asc file is generated by the nextpnr command, not supplied to it
- the icetime tool is not covered here
- nextpnr also has gui


### Pinouts for the ICE40 IceStick
They are detailed in full in the datasheet near the end. [pdf](obsidian://open?vault=Obsidian%20Vault&file=Hardware%2FEB82-iCEstick_User_Manual.pdf)

For easy reference, the clock is pin 21.

Pin assignemnts are put in a .pcf file and look something like the following:
```
set_io <name_in_RTL> <pin>
# for an LED
set_io led1 99
```

### Utilizing Block Memory Cells
Can be inferred by yosys if the correct structure is used, below is an example that works.
```
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity BRAM is  
   port (clk   : in  std_logic;  
         addr  : in  std_logic_vector(7 downto 0);  
         d_in  : in  std_logic_vector(7 downto 0);  
         we    : in  std_logic;  
         d_out : out std_logic_vector(7 downto 0));  
end BRAM;  
  
architecture behav of BRAM is  
   type ram_type is array (0 to 255) of std_logic_vector(7 downto 0);  
  
   signal ram : ram_type;  
begin  
   process(clk)  
   begin  
       if (rising_edge(clk))  
       then  
           if (we = '1') then  
               ram(to_integer(unsigned(addr))) <= d_in;  
           end if;  
               
           d_out <= ram(to_integer(unsigned(addr)));  
       end if;  
   end process;  
end behav;
```
What is important about this above piece is the port configuration, for some reason yosys will only infer block RAM when there is an input and output port set. More information on memory in the Ice40 can be found in the [pdf](obsidian://open?vault=Obsidian%20Vault&file=Hardware%2FMemoryUsageGuideforiCE40Devices.pdf). 
NOTE: The Ice40 does not have distributed RAM capabilities (use the LUTS as RAM).
