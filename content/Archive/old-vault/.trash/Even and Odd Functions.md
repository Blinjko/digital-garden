
## Even Function
An even function is a function that satisfies the following criteria.
$$
f(t)=f(-t)
$$
That is to say it is symmetrical about the vertical axis. $\cos(t)$ is an example of an even function.

## Odd Function
An odd function is a function that satisfies the following relation.
$$
f(t)=-f(-t)
$$
That is to say it is anti-symmetrical about the vertical axis. An example of an odd function is $\sin(t)$


## Decomposing a function into even and odd parts
A function may not be even or odd, but it can be decomposed into even and odd parts.
