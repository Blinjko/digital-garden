A causal system is a [[systems|system]] that, simply put, doesn't predict the future. That is to say, it's output at any given moment only depends on the current and past inputs / state of the system. 

Causal systems are able to be realized in real time since they don't rely on future inputs to produce past and current outputs.

## Determining if a system is causal
If we have the [[Impulse Response]] of a system we can look if it is defined for any time before 0. If it has some sort of output before 0 that means the system is [[Non Causal Systems|non-causal]].
