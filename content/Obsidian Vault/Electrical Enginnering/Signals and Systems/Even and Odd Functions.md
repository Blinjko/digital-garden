
## Even Function
An even function is a function that is symmetrical about the vertical axis. That is to say:
$$
x(t)=x(-t)
$$

## Odd Function
An odd function is a function that is anti-symmetrical about the vertical axis.
$$
x(t)=-x(-t)
$$

## Properties of Even and Odd Functions
1. Even function x even function = even function
2. Odd function x odd function = even function
3. Odd function x even function = odd function

Also, some integrals. Let $f(t)$ be even and $g(t)$ be odd.
$$
\int_{-a}^{a}f(t)dt=2\int_{0}^{a}f(t)dt
$$
$$
\int_{-a}^{a}g(t)dt=0
$$
Assuming there is no impulse for its derivatives at the origin of the functions.

## Decomposing a function into even and odd parts
A function may not be even or odd, but we can decompose it in such a manner that it is the sum of an even function and an odd function. Given the function $f(t)$ the formula is as follows.
$$
f(t)=\frac{1}{2}[f(t)+f(-t)]+\frac{1}{2}[f(t)-f(-t)]
$$
Where the even part is given by:
$$
f_{even}(t)= \frac{1}{2}[f(t)+f(-t)]
$$
And the odd part is given by:
$$
f_{odd}(t) = \frac{1}{2}[f(t)-f(-t)]
$$This comes in later when we decompose a function as sine and cosine.
